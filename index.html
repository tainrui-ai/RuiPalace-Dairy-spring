使用说明
使用说明与版权指引
🌸 1. 书卷翻阅与日记落笔
在首页点击“翻开书卷”即可进入目录。您可以按月份查看过往藏珍，或点击右上角“书写新日记”记录当下的节气与心境。落笔时支持自由更换花卉贴纸、调整贴纸角位，并可点击底部诗词切换多语种春日名句。
📥 2. 导出备份（本地存档与隐私）
位于首页底部的“导出备份”按钮，可将您所有的日记数据打包生成一个本地 JSON 文件。本系统采用纯前端本地存储（LocalStorage），您的文字心血完全掌握在您自己手中，注重绝对的隐私安全。建议定期导出备份。
🔄 3. 恢复备份（数据导入）
若更换了浏览器、设备或清除过本地缓存，可点击首页底部的“恢复备份”按钮，选择以往导出的 JSON 备份文件即可一键还原全部日记内容。
🌐 4. 多语言支持与交互体验
本站完美支持中、英、德、法、俄、西六种语言。切换语言后，使用说明及整站文案将同步无缝转换。排版与交互设计均充分契合东方式极简美学。
