# 🌸 Welcome to Spring Mood E-Journal

Thank you for choosing Spring Mood—a private, 100% offline digital sanctuary inspired by traditional oriental aesthetics.

### 📦 Installation & Quick Start
1. Unzip the downloaded package "RuiPalace-Dairy-springmood.zip" into a safe, designated folder on your local hard drive.
2. Open the folder and double-click "index.html" to launch your journal instantly in any modern browser. No internet connection or installation required.
3. Tip: Add the opened local page URL to your browser's Favorites/Bookmarks so you can easily access it next time.

### 🛡️ Absolute Privacy (100% Offline)
- All journal entries are stored securely on your local device. Zero cloud servers are used, ensuring complete privacy.

### 🔄 Data Safety & "Double Insurance" (CRITICAL)
- Because this is an offline app, please remember to regularly click "Export Backup" on the homepage to save your data as a local JSON file. 
- This serves as a vital "double insurance" to prevent data loss if your browser updates or cache clears. You can restore your data anytime using "Restore Backup".
